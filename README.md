## 🛠️ Quick Start

1. **Install Requirements:**
   - Figma Desktop App
   - Cursor IDE
   - Node.js

2. **Get API Token:**
   - Figma → Settings → Security → Personal Access Tokens

3. **Configure MCP Server:**
   - Add to `~/.cursor/mcp.json`
   - Restart Cursor

4. **Start Using:**
   - Copy Figma link
   - Paste in Cursor Composer
   - Add clear prompt
